what it is

Strongroom cloud is my personal storage cloud that i can access from anywhere. I built it because im getting into homelabbing and this was a perfect project for this. Now i never have to pay for cloud storage again.

I made this with a lot of help from AI. I came up with the idea and what it should do, and kept testing and tweaking it until it worked how i wanted.

how it's built

It's built with Node JS + Express for the backend and plain HTML, CSS and Javascript for the frontend. No frameworks or build step.

  • Accounts and the audit log are stored in an SQLite database using better-sqlite3
  • Auth: JWT in secure cookies and passwords are hashed with bcrypt
  • Admins can create accounts, set a storage quota per user and see a log of every login, upload, download and deletion
  • Upload single files, batches or whole folders and download folders as a zip
  • Preview images, PDFs and text files right in the browser
  • Every user also gets SFTP access to their own folder with the same login, so it can even sync with Windows Explorer through rclone
  • A GitHub puller: paste a repo link and the server clones it for you with a live log

what i learned

I learned more about backend and actually hosting services. How to work with cloudflare and other systems
