project

Skript Extension

A VS Code extension for Skript that adds the stuff the other Skript extensions are missing. Variable autocomplete, auto indentation, snippets, function intellisense and more!

Download ↗ View code ↗

what it is

I write a lot of Skript and the Skript extensions on the marketplace just weren't good enough. So i made my own. It knows every variable and function in your whole workspace, fixes your indentation when you save and warns you about mistakes before Skript even loads the file.

I made this with a lot of help from AI. I came up with the idea and what it should do, and kept testing and tweaking it until it worked how i wanted.

how it's built

It's built in plain JavaScript with the VS Code extension API.

  • Syntax highlighting with a full TextMate grammar. Minecraft & colour codes even show up in their real colour
  • Every .sk file in your workspace gets indexed, so you get autocomplete, go to definition and find references for variables and functions
  • Doc comments (#d, #dp, #dr) show up when you hover over a function
  • A formatter that only fixes the indentation mistakes Skript would reject and leaves valid code alone
  • Warnings for stuff like a wait inside on inventory click or calling a function that doesn't exist
  • Comes with its own theme: Skript Tools Dark

What I learned

I learned how to upload vscode extensions and how to use AI in a different aspect of programming by making a tool instead of a piece of software.
